Built to be checked

You are trusting this app with your family's IDs, so here is exactly how it protects them, with the real algorithm names and the limits.

  • One random master key locks everything. Your password only locks that key, so changing it never re-encrypts your documents.
  • Your password goes through Argon2id, which is slow on purpose, so every guess costs an attacker real work.
  • The database uses SQLCipher and every scanned page uses AES-256-GCM. Standard algorithms, nothing home-made.
  • The only internet use is a once-a-day update check, which you can turn off. No account, no ads, no analytics.
  • Every release is signed with the same key. Its fingerprint is listed under Questions below.

Questions

Is it safe to install an app from outside the Play Store?

Android warns about every app that doesn't come from the Play Store; it doesn't mean the app is harmful. Every Tijori release is signed with the same key, and Android refuses any update not signed with it, so after you install, only genuine updates can replace it.

Does it cost anything?

No. Tijori is free, with no ads and nothing to buy.

What happens if I lose my phone?

Your documents are encrypted, so whoever finds the phone can't read them without your password. To get them back on a new phone, keep a backup: in Tijori, go to Settings, then Backup, and save the encrypted backup file to Google Drive or anywhere you like.

Will it get updates?

Yes. Tijori checks for a new version once a day and asks before updating. You can turn this off in Settings.
